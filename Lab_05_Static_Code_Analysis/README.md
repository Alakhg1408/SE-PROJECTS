## Project Description

This lab focuses on performing static code analysis on the **E-commerce Cart System** using automated linters and code checkers (such as Flake8, Pylint, and Bandit).

The analysis identifies:
- Code smells, bad practices, and design anti-patterns.
- PEP 8 style violations and convention deviations.
- Security vulnerabilities, hardcoded values, and insecure method calls.
- Unused variables, dead code, and overly complex control flow.
