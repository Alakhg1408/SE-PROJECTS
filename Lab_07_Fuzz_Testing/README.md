## Project Description

This lab implements property-based testing and fuzz testing using **Python Hypothesis** and **pytest** on the **Fuel Station Management System**.

The testing aims to:
- Generate high-volume, randomized, and edge-case inputs (negative values, extreme floating-point amounts, invalid fuel types, null payloads).
- Identify unexpected runtime exceptions, boundary errors, and arithmetic overflow/underflow issues.
- Verify defensive input validation and domain invariants under erratic conditions.
