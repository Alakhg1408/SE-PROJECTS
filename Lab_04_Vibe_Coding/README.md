## Project Description

Target Aim Trainer is an interactive 2D desktop game developed using Python and **Pygame**. The game challenges players to click dynamic, shrinking circular targets on screen to build aiming precision, reaction speed, and accuracy under a round countdown timer.

Through iterative prompt engineering and AI-assisted pair programming, bugs in the initial implementation were resolved and several new gameplay features were incorporated.

- **`after.mov`**: 10-second gameplay recording showing the fully fixed, polished game with dynamic collision detection, difficulty selection, sound effects, and game over screen.

---

## Key Features & Enhancements

- **Dynamic Collision Detection:** Refined click detection so target hitboxes scale exactly with the visual shrinking circle.
- **Game Over & Analytics Screen:** Clear display of total targets hit, misses, elapsed time, and accuracy percentage.
- **Difficulty & Replay Mechanism:** Easy, Medium, and Hard presets altering target lifespan and radius with an instant replay prompt.
- **Audio Feedback:** Sound feedback for hits, misses, countdown, and round completion.
